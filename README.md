# CekSaldo & Kalkulator Tarif Tol (100% Gratis & Tanpa Iklan/Langganan)

Aplikasi Android Open-Source untuk:
1. **Cek Saldo E-Money via NFC** (Mandiri e-Money, BNI TapCash, BCA Flazz, BRI Brizzi) menggunakan sensor NFC bawaan HP Android (`IsoDep` APDU).
2. **Kalkulator Tarif Tol Seluruh Indonesia (Golongan I - V)** lengkap dengan pengecekan kecukupan saldo otomatis.
3. **100% Gratis Selamanya** — Tanpa biaya langganan, tanpa paywall, dan tanpa iklan.

---

## Cara Mengubah Project Ini Menjadi File `.apk` Secara Gratis (Tanpa Laptop / Tanpa Biaya)

Jika Anda hanya menggunakan HP Android dan ingin mendapatkan file `app-debug.apk`:

1. Buat akun gratis di [GitHub.com](https://github.com) dan buat **New Repository** baru.
2. Upload seluruh isi folder/zip ini ke repository tersebut.
3. Buka menu tab **Actions** di repository GitHub Anda, lalu klik workflow **Build Free APK** -> **Run workflow**.
4. Tunggu sekitar **1-2 menit** hingga proses selesai, lalu unduh file **`CekSaldo-Tol-Gratis-APK` (`app-debug.apk`)** langsung ke HP Anda!

## Cara Build Menggunakan Android Studio (Jika Menggunakan PC/Laptop)
1. Ekstrak file `.zip` ini dan buka foldernya di **Android Studio**.
2. Pilih menu **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
3. File `.apk` siap diinstal di HP Android Anda.
